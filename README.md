# P1｜电商平台用户行为分析与高潜用户画像

> 定位：从「海量用户行为日志」中识别高潜用户，并给出可落地的运营策略。
> 数据：京东式电商行为日志（2016.01–2016.04，约 2.2 GB CSV，月均百万级行为）
> 技术栈：Python / Pandas（chunked 分块处理）/ SQL（等价逻辑可迁移）/ Excel·BI 可视化

---

## 1. 业务背景与问题

某电商平台每天产生海量用户行为数据（浏览、点击、加购、关注、下单、删购），但运营资源有限。

**核心业务问题**：
1. 哪些用户是「高潜用户」（有购买意向、但决策周期 > 1 天，值得重点触达）？
2. 高潜用户在人口属性、会员等级、品类偏好上与普通用户有何差异？
3. 如何用数据支撑「分层运营 + 精准触达」？

> 本项目的价值不是"画几张图"，而是：**定义高潜用户 → 量化其价值 → 输出分层运营策略**。

## 3. 分析框架（5 个模块）

| 模块 | 内容 | 产出 |
|---|---|---|
| **M1 数据画像** | 行数、时间跨度、用户数、行为分布、品类分布、缺失 | 数据质量报告 |
| **M2 行为漏斗** | 浏览 → 点击 → 加购 → 关注 → 下单 的转化漏斗与品类差异 | 漏斗图 + 转化率 |
| **M3 高潜用户识别** | 定义并计算：有购买 + 首次交互到购买时间差 > 1 天 | 高潜用户名单 + 规模 |
| **M4 用户画像对比** | 高潜 vs 普通：年龄、性别、等级、购买量、品类偏好 | 对比画像 |
| **M5 业务策略** | 分层运营建议（触达时机、品类、人群） | 策略清单 + 报告 |

### 高潜用户定义（对齐课程，并做增强）

- 必要条件：**有下单行为（type=4）**
- 时间条件：**首次交互时间** 与 **最后购买时间** 的时间差 **> 1 天**
- 增强维度（比课程版多）：
  - 加入购物车/收藏/关注等"高意向行为"权重
  - 区分"品类级"与"SKU 级"两种颗粒度
  - 计算高潜用户的 **客单价 / 复购 / 品类集中度**

## 4. 技术方案（可复用于面试讲述）

数据 2.2 GB、约 4000 万行，**不能一次性 load 进内存**，采用工程化处理：

```
01_profile.py      # 分块扫描：行数/时间跨度/行为分布/用户数（画像）
02_aggregate.py    # 分块聚合，产出紧凑中间表（核心）
   ├─ user_behavior.csv    # 每用户：各行为次数、首末时间、SKU/品类数
   ├─ user_cate_order.csv  # 每(用户,品类)：下单数、首交互、末下单
   ├─ daily_stats.csv      # 每日：DAU、下单量、各行为量
   └─ cate_stats.csv       # 每品类：行为/下单分布
03_high_potential.py  # 高潜用户识别 + 静态属性 join
04_analysis.py     # 画像对比、漏斗、周内规律 → 图表 + 结论
```

**为什么这样设计**：一次扫描产生中间表，后续所有分析只读小表 —— 既省内存又可在面试中讲"大数据处理的分层聚合思路"。

## 8. 首轮结果（2026-11-23 已完成）

| 指标 | 结果 |
|---|---|
| 总行数 / 大小 | 50,601,736 行 / 2.19 GB |
| 覆盖用户 | 105,180（用户表 105,321，覆盖 99.9%） |
| 买家率 | 28.03%（29,485 人） |
| 决策型高潜 | 26,385 人（占买家 89.5%） |
| 高潜 vs 快速人均下单 | 1.686 vs 1.218（+38.4%） |
| 高意向未购 | 47,497 人（加购/关注未下单） |
| 加购→下单转化 | 41.5% |
| 课程口径（cate 4）高潜 | 6,270 人 |

**关键结论**：
1. 该平台"多日决策"是常态，89.5% 买家决策周期 > 1 天，但决策久的人客单更高。
2. 最大增量池是 **47,497 名加购未购用户**（加购→下单仅 41.5%）。
3. 高潜用户集中在 **会员等级 5（50.1%）** 与 **age=3 段（49.5%）**。
4. **cate 8 是流量型品类**（转化 9.67%），**cate 7 转化最高（24.04%）**。
5. 工作日下单显著高于周末，**周二日均 806 单为峰值**。
